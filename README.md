## 中文

### 主要功能

- **批量自动插入**：自动识别Word文档中所有“2列4行”的表格结构（第1、3行为图片框，第2、4行为标题行），并自动跳过标题行，精准插入图片。
- **保持比例，完美居中**：图片插入后自动保持原始比例，最大化缩放以适应单元格，并在单元格内居中显示，不会变形。
- **浮于文字上方**：图片以“浮于文字上方”方式呈现，不改变表格原有结构，不影响后续编辑。
- **自然排序**：自动按文件名中的数字（如1.jpg、2.jpg、10.jpg）进行自然排序，确保图片顺序正确。
- **图形化操作界面**：提供简洁的GUI界面，支持选择Word文档、图片文件夹、排序方式（升序/降序）。
- **自动清理进程**：运行前自动清理后台残留的Word进程，避免文件被锁定，减少人为操作。

一、 软件简介
本工具是一款基于 AutoHotkey 开发的 Word 文档辅助工具，主要用于在包含多页“2列4行”表格的 Word 文档中，自动批量插入对应顺序的施工图片。图片插入后自动保持原始比例，并居中放置在单元格内，且以“浮于文字上方”方式呈现，不会破坏原表格结构。

二、 系统要求

操作系统：Windows 7 及以上版本（支持32位及64位）。

必备软件：Microsoft Word 2010 及以上版本（必须已安装且能正常打开文档）。

如果运行的是 .ahk 源码，请确保已安装 AutoHotkey v2.0 及以上版本；如果是打包后的 .exe 文件，则无需安装 AutoHotkey。

三、 准备工作（非常重要）

Word 文档要求：目标 Word 文档中必须是“2列4行”的表格结构（您的原模板）。第1行和第3行为大格子（将插入图片），第2行和第4行为小格子（标题行，程序将自动跳过）。文档中可包含多个这样的表格（即多页）。

图片文件夹要求：将所有需要插入的图片放置在同一个文件夹内。图片文件需为 .jpg、.jpeg、.png、.bmp 或 .gif 格式。请务必按照插入顺序对图片进行命名（如 1.jpg、2.jpg、10.jpg），程序会自动按文件名中的数字（自然排序）依次读取。

四、 操作步骤

关闭所有正在打开的 Word 文档（尤其是待处理的文档），避免文件被锁定无法编辑。

双击运行本工具（.exe 或 .ahk）。

点击“浏览”按钮，选择待处理的 Word 文档。

点击“浏览”按钮，选择存放图片的文件夹。

选择“排序方式”（推荐使用“升序”，即按图片名称从小到大排列）。

勾选“保持图片比例并居中”（默认已勾选，请保持勾选状态，这样图片不会变形，且能尽量填满单元格）。

点击“开始处理”按钮。

程序将自动启动 Word（窗口显示为最小化），处理完成后会弹出提示框，显示成功插入的图片数量。

五、 常见问题及处理

提示“图片文件夹中没有找到匹配的图片”：请检查图片后缀名是否为小写，或者文件夹路径是否包含特殊字符。

弹出“文件正在使用被锁定”：请完全关闭所有 Word 窗口，并确保没有后台残留的 Word 进程，然后再运行本工具（工具已内置自动清理功能，但手动关闭更保险）。

提示“插入图片失败”：通常是因为图片文件损坏或格式不支持，请检查对应编号的图片。
